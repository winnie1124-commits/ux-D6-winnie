Learning Path

課程核心學習地圖

循序漸進地從 UX 規劃、前端語法基礎到 AI 開發協作，建立能持續調整升級的網站實體。

五大學習模組

著重觀念建立與動手實作，每個模組都有明確的進度交付目標。

01

從 UX 開始規劃網站架構

學習定義目標使用者與網站核心任務，讓內容及網站架構符合使用者需求。

UX 規劃 使用者需求分析 網站地圖
02

HTML & CSS 網頁視覺基礎

理解網頁語意化結構，並運用 CSS 進行樣式設定、元件排版與 RWD 尺寸適應。

HTML5 語意化 CSS 排版 主題色彩設計
03

JavaScript & JSON 資料管理

學習用 JavaScript 讀取 JSON 資料檔，將文字內容與網頁版型分開管理，之後只要修改資料檔，就能更新頁面內容。

原生 JS Fetch API JSON 格式化
04

AI 輔助內容與資料生成

設計明確的 Prompt 指令，引導 AI 產生符合需求格式的網站文案，提高品牌內容產出效率與品質。

Prompt 工程 AI 內容生成 JSON 結構輸出
05

AI 前端協作與錯誤排除

掌握準確描述需求與錯誤訊息的技巧，讓 AI 成為精準除錯夥伴，並完成風格一致的多頁面網站。

Console 檢測 AI 除錯協作 靜態部署

課堂實作流程

從需求整理到網站上架，帶你掌握 AI 協作與前端實作的完整工作流。

STEP 01

UX 需求與架構梳理

釐清目標使用者、品牌定位與網站任務，規劃首頁與其他頁面的資訊層級。

STEP 02

AI 協作生成 JSON 資料

透過精準 Prompt 引導 AI 產出專屬品牌文案，並生成結構正確的 JSON 資料檔。

STEP 03

前端渲染與樣式微調

運用 JavaScript 動態讀取 JSON 呈現內容，並透過 CSS 調整視覺風格與版面配比。

STEP 04

版本控制與 GitHub 上架

建立 Git 版本控制概念與更新邏輯，將專案推送至 GitHub Pages 完成網站實作發布。
